## 规则列表

| ID | 规则 | 校验时机 | 实现层 | 违反处理 |
|---|---|---|---|---|

| R-02 | **禁止开具处方/用药剂量** — 不得给出药物名称+剂量组合 | 所有面向用户输出 | 编排层正则门 | 拦截 + 拒答 |
| R-03 | **禁止替代医生** — 不得声称替代/等效于医疗建议 | 所有面向用户输出 | 编排层正则门 | 拦截 + 补充就医引导 |
| R-04 | **禁止制造恐慌** — 不得使用危言耸听措辞（"会猝死""晚期"等） | 所有面向用户输出 | 编排层正则门 + LLM-as-judge 兜底 | 拦截 + 温和化改写 |
| R-05 | **单样本禁止断言** — 不得基于单条记录断言规律/趋势 | Analysis 输出 | 编排层规则（样本量≥N 才允许"趋势"表述） | 降级为"观察到一次"描述 |
| R-06 | **来源可追溯** — 故事/洞察/建议必须带数据来源、时间窗口、置信度 | Analysis / Story 输出 | 编排层结构校验（必填字段） | 拒绝入库/出库，标记待补 |
| R-07 | **建议范围边界** — 超出"生活方式干预"范围（如需用药/手术）一律拒答并引导就医 | Planning 输出 | 编排层分类门 + LLM-as-judge | 拦截 + 就医引导 |
| R-08 | **知识库引用规范** — 引用白名单内来源方可作为科学依据 | Planning 输出 | 编排层白名单校验 | 无来源引用则拦截 |
| R-09 | **不阻塞日常推进** — 安全校验层缺失时，不得阻断 Phase 3/4 已有功能的日常迭代 | 全局 | 编排层降级开关 | 记录 warning，不阻断非健康功能 |

## 实现分层

| 层 | 承担规则 | 特点 |
|---|---|---|
| **编排层正则门（rule-based gate）** | R-01/02/03/04(部分)/05/08 | 快、可解释、可测试、零成本 |
| **编排层结构校验** | R-06 | 必填字段检查，保证可追溯链 |
| **LLM-as-judge（兜底）** | R-04(语义)/R-07 | 处理语义级越界（不在禁词表但措辞越界） |
| **降级开关** | R-09 | 未上线安全层前保证迭代不阻塞 |

## 关键定义

- **"生活方式干预"范围**：饮食、运动、睡眠、压力管理、作息、习惯养成。超出（症状诊断、药物、器械、手术、精神疾病判定）一律拒答并引导就医。
- **置信度标注**：Analysis 输出必须带 `confidence ∈ [low, medium, high]`，low 时故事/交互端必须口语化弱化（"可能""有时"），不得作为确定事实。
- **样本量阈值**：默认 N≥3 才允许"趋势"表述；N=1 只允许"观察到一次"。
