# Viora

> 不是健康应用。是主动关心你的身体搭子。
>
> *Listen to your body, lightly — and let someone gently check on you.*

Viora 是一个面向年轻人的**主动式 AI 身体搭子**。

它不做打卡、不记分、不催你"今天还没记录哦"。它会像朋友一样主动找你聊天——在你作息异常的时候、天气变化的时候、或者它感觉你状态不太对的时候。信息从朋友式的聊天中自然获取，你不会觉得自己在"记录"，但 Viora 从对话中默默记住了你的节奏。体检数据、日常感受、聊天内容，最终会编织成可回看的身体故事——用一张图谱，把所有线索连在一起。

它不是一个每次都要重新解释的陌生人。它是一个记得你习惯、懂你节奏的"熟人"。它有自己的性格——有点幽默、关心你但不唠叨——你也可以把它改成你想要的样子，比如健身教练、中医阿姨、毒舌闺蜜。

---

## 和别的健康应用不一样在哪里

市面上的健康工具大致分两类：

- **数据型**：给你一堆数字和图表，但数字本身不会讲故事
- **打卡型**：用连续天数、徽章、排行榜驱动你，但越用越像上班

Viora 走第三条路：**AI 主动关心你，像朋友一样。**

| | 别的 AI 健康工具 | Viora |
|---|---|---|
| 谁先开口 | 你先说话，它才回 | AI 也会在适当时机主动找你 |
| 信息获取 | 你主动记录 / 填表 | 朋友式聊天中自然获取 |
| 关系 | 每次像第一次对话 | 长期记忆，像熟人一样记得你 |
| 性格 | 千篇一律的机器回复 | 有性格、有温度、可自定义 |

- 输入方式：不是填表，是**朋友聊天**。Viora 主动找你，你随口回几句，信息就自然收集了
- 反馈方式：不是报表，是**身体故事**。把你的睡眠、精力、情绪、胃……串成一段可读的叙事
- 关联发现：不是分类存储，是**图谱**。让你看到"原来睡眠差的两天后，精力总是会低"
- 主动关心：不是等你打开 app，是**AI 主动找你**。在你作息异常、天气变化、该运动的时候轻声说一句

不 gamification、不施压、不评判。你可以三天不说话、也可以一天聊五条——系统不在乎，它只是安静地帮你记住。

## 核心玩法

### 1. AI 主动找你聊天

不是等你来问，是 AI 主动关心你：

> "你今天应该去跑步了吧，但一直没动静，计划改了吗？"

不是问答题式的"你今天运动了吗"，而是朋友式的自然聊天：

> "今天天气这么好，你上次不是说想多走走吗？"

你随口回几句，Viora 从对话中自然提取了健康数据——你甚至没觉得自己在"记录"。

### 2. 悄无声息地了解你

Viora 不是通过问卷了解你的。它在日常聊天中逐渐摸清你的节奏：

- 你几点起床、几点睡
- 你通常吃什么、怎么运动
- 你熬夜之后第二天会怎样
- 你胃不舒服和什么有关

你不需要主动填报。这些信息从朋友式聊天中自然获取。

### 3. 有性格的 AI 朋友

Viora 不是冷冰冰的机器，它有性格：

> "你这两天睡得比猫还少啊，没事吧？"

默认是"关心你但不唠叨、有点小幽默的熟人朋友"。你也可以自定义——健身教练、中医阿姨、毒舌闺蜜，随你选。

### 4. 身体故事

系统把你的记录编织成可读的叙事：

> 这周你的身体像一部开了省电模式的手机。
> 周三到周五，你的睡眠都在 6 小时以下，
> 每天的精力评分也跟着降到了"勉强够用"。
> 好在周末补了一觉，周日精力回到了正常线。

### 5. 图谱洞察

一张关系图展示你身体各维度之间的关联：

- 节点：睡眠、精力、情绪、肠胃、皮肤、运动……
- 连线：关联强度（如"睡眠差 → 精力低"的关系有多强）
- 时间滑块：拖动时间，看关联如何演变

### 6. AI 趋势发现

> 你倾向于在睡眠差的 **2 天后** 出现精力偏低。
> 当你运动了的时候，当天情绪偏高的概率是 **72%**。

这些都是基于你个人真实记录的观察，不是通用的健康建议。每个洞察都标注置信度和记录数量。

### 7. 分层图谱理解

Viora 的图谱可视化不只展示健康指标之间的关系，还会逐步承载四层抽象：

- **事件层**：从聊天里抽取的具体事件，如“周四下午两点困得不想上课”
- **状态层**：短期聚合出的状态，如“近期睡眠不足”“下午易犯困”
- **轨迹层**：跨时间窗口沉淀出来的稳定模式，如“周四下午低能量”“熬夜后次日精力低”
- **Personality 层**：长期稳定倾向，如“偏内倾”“压力下回避任务”“易焦虑”

这几层会并到现有的图谱可视化里，通过时间滑块、层级切换、节点下钻来查看。

## 反馈功能

点击顶栏的 **📋 反馈** 按钮即可打开反馈与待办面板。你可以：

- **提交 Bug 报告** — 记录使用中遇到的问题
- **提交体验建议** — 分享改进点子和使用感受

每条反馈都是一个待办项，支持勾选标记完成和删除，方便跟踪处理进度。

### Agent 维护指南

当你（AI agent）被要求维护 Viora 或修 bug 时，按以下流程处理用户反馈：

**1. 查看反馈列表**

```bash
cd /mnt/chengrongfeng_private/cc_dump/viora && python3 -c "
import json
with open('data/feedbacks.json') as f:
    feedbacks = json.load(f)
for fb in feedbacks:
    status = '✅' if fb['completed'] else '⬜'
    print(f'{status} [{fb[\"type\"]}] {fb[\"user_id\"]} | {fb[\"description\"]} | id={fb[\"id\"]}')
"
```

反馈数据文件：`data/feedbacks.json`，每条记录包含 `id`、`user_id`、`type`(bug/ux)、`description`、`completed`、`created_at`。

**2. 修复问题**

根据反馈内容定位并修复代码，修改后重启服务：

```bash
pm2 restart viora
```

**3. 标记已完成**

修复后将该反馈标记为完成，用户下次打开面板即可看到状态更新：

```bash
curl -X PUT http://127.0.0.1:5050/api/feedback/<feedback_id> \
  -H "Content-Type: application/json" \
  -d '{"completed": true}'
```

或者直接用 Python：

```bash
cd /mnt/chengrongfeng_private/cc_dump/viora && python3 -c "
from feedback import update_feedback
# <feedback_id> 替换为实际 ID
update_feedback('<feedback_id>', '<user_id>', completed=True)
print('已标记完成')
"
```

> 注意：update_feedback 需要提供正确的 `user_id` 才能配对成功，可从反馈列表中获取。

## 目标用户

20-35 岁的都市年轻人：

- 70%+ 有亚健康困扰，但体检报告没有明确的"病"
- 不想被健康管理工具绑架——下载了、用了三天、不想填表了、卸载了
- **不希望有个机器人每天问她"今天运动了吗"——希望有个能主动关心她、又不会让她觉得被打扰的人**
- 想要一个"熟人"，不是每次重新解释的陌生人
- 用微信发语音多于打字，聊天是最自然的沟通方式

Viora 服务的是那些**想对自己的身体多一点了解、但不想多一分负担**的人。

## 核心理念

- **主动智能** — AI 主动找你聊天，不是等你来问
- **熟人关系** — 长期记忆、长期关系，不是每次重新解释的陌生人
- **摸清 routine** — 理解你的日常节奏，在合适的时机出现
- **悄无声息的信息收集** — 朋友式聊天中自然获取，不是问卷打卡
- **AI 有 Persona** — 有性格、有温度、可自定义的 AI 朋友
- **身体故事 > 数据报表** — 数据是原料，故事才是产品
- **图谱即洞察** — 图谱不是装饰，是发现身体关联的工具
- **零压力** — 没有 streak、没有推送、没有"你 X 天没记录了"
